# agate-tool-server

株式会社アゲイトの物販ツール(ダッシュボード)用の、受け取りサーバーのセットアップコードです。

**このリポジトリにはプログラムのコードだけが入っています。売上・在庫・個人情報などの業務データは一切含まれていません。**

## これは何をするもの?

物販ツール(ダッシュボード)の「保存」ボタンを押したときに、ダウンロード→チャットに貼り付ける、という今までの手間をなくし、サーバーに直接データを送って保存できるようにするための小さなプログラムです。

## サーバーへのインストール方法

Ubuntu 24.04 のサーバー(git・Node.js がインストール済み)のコンソールで、以下を1行だけ実行してください。

```
git clone https://github.com/corpagate-svg/agate-tool-server.git && cd agate-tool-server && bash install.sh
```

`install.sh` が、必要な設定(HTTPS化・自動起動など)をすべて自動で行います。最後にアクセス用のURLと秘密のトークン(合言葉)が表示されるので、必ず控えておいてください。

## 構成

- `server/server.js` — データを受け取って `data/売上管理表.xlsx` に保存する本体プログラム(Node.js)
- `install.sh` — 上記プログラムをサーバーに設置し、自動起動・HTTPS化まで行うセットアップスクリプト
- `systemd/agate-tool-server.service` — サーバー再起動時にも自動でプログラムが立ち上がるようにする設定
- `Caddyfile.template` — HTTPS化(暗号化通信)のための設定のひな形
